✅ Checklist before Run / Submit

  • Is the loop variable an item or a position? Did I name it after what it is?
  • Does my range give exactly the right first and last values?
  • Am I replacing (=) or adding on (+=)?
  • Text or number? Do I need int() / float() / str()?
  • Could uppercase break it? Use .lower()
  • Want the first match? Did I break?
  • Does every while change something so it can stop?
  • Does my function return (not print)?
  • Did I test a tricky input (duplicates, boundaries like exactly 90, empty)?

1 · print, variables, f-strings

↑ contents
name = "Gowri"            # a variable is a labelled box holding a value
age = 31
print("My name is", name)  # My name is Gowri    (commas → a SPACE)
print(f"Next year: {age + 1}")   # Next year: 32  (f-string: {} is replaced)
print("A", "B", "C", sep="-")    # A-B-C          (sep = what goes between)
print("Hi", end="")              # no newline, the next print continues here
print("!")                       # Hi!
avg = 26.5
print(f"{avg:.2f}")              # 26.50          (2 decimal places)
❌ What I did
print("age", age "next", age+1)   # SyntaxError
print(f"{robot} is{robot_age}")   # Optimus is2
✅ Right
print("age", age, "next", age + 1)
print(f"{robot} is {robot_age}")  # spaces print as typed

🔑 Remember

  • The commas in print(a, b) are code: Python prints a space. Only text inside quotes (or sep=) appears on screen.
  • {x} means "insert value" only inside f-strings.

4 · Loops ⭐

↑ contents

🔴 My #1 mistake (8 times!): items vs positions

LoopGives youUse it as
for num in nums:items: 1, 2, 1num directly
for i in range(len(nums)):positions: 0, 1, 2nums[i]

Before writing x[something], ask: "is something a position or an item?" If it came from for something in x, it's an item. Name loop variables after what they are (num, name = item · i = position).

❌ What I did (LeetCode 1929)
nums = [1, 2, 1]
for i in nums:
    ans.append(nums[i])   # nums[1], nums[2], nums[1]
# → [2, 1, 2]  wrong!
✅ Right
for num in nums:
    ans.append(num)
# → [1, 2, 1]

range()

CodeGives
range(5)0, 1, 2, 3, 4 (stops before 5)
range(1, 6)1, 2, 3, 4, 5
range(2, 21, 2)2, 4, … 20 (step)
range(len(x) - 1, -1, -1)positions backwards: 4, 3, 2, 1, 0
range(nums) ❌TypeError: range needs a number → range(len(nums))

while

count = 3
while count > 0:
    print(count)
    count -= 1      # MUST change, or it runs forever
print("Liftoff!")

TLE "Time Limit Exceeded" usually means an endless while.

break · continue · pass

for n in [1, 2, 3, 4]:
    if n == 2:
        continue    # skip this round
    if n == 4:
        break       # stop the WHOLE loop
    print(n)        # 1, 3
# pass = do nothing (placeholder)
❌ Other loop traps
for name in ["A", "B", "C"]:
    pass
print(name)      # "C": keeps the LAST value!

for letter in s:           # loop never needed
    while first < last: …  # reverses len(s) times
✅ Remember
  • Use the variable that holds what the question asks for, not a leftover loop variable.
  • Off-by-one: range(0, n + 1) gives n+1 items. range(n) gives exactly n.
  • for _ in range(n): → "repeat n times, I don't need the counter".
  • Loop variable never used? Ask "do I need this loop at all?"

🔑 Strings can't change

Methods return a new string. Save it: name = name.strip(). Building text with s = s + ch in a loop makes a new string every round, so for huge texts collect a list and "".join() once.

🔑 Comparing is case-sensitive

"Racecar" == "racecaR"   # False
w = word.lower()
w == w[::-1]             # palindrome ✅
❌ What I did

i.index[i]            # methods use ( ) not [ ]
✅ Right
for ch in word:
    print(ch)         # use the letter directly
"Robot"[::-1].lower() # chaining: left → right → "tobor"

📚 In place vs new (the bookshelf)

.sort(), .append(), .reverse(), s[i] = … rearrange the same shelf. sorted(), s[::-1], + make a new shelf. s = … only moves the label to a new shelf.

Nested lists

students = [["Harry", 37.21], ["Tina", 37.2]]
students[0]        # ["Harry", 37.21]
students[0][1]     # 37.21
for name, score in students:
    print(name, score)

⚠️ Never call a variable list, str, dict, int

len(list) → "object of type 'type' has no len()". Those names belong to Python. Use the parameter name (nums).

7 · Functions

↑ contents
def power(base, exp=2):    # parameters, with a default value
    return base ** exp     # return HANDS BACK the value

result = power(3)          # 9
print(power(2, 5))         # 32
❌ print instead of return
def average(nums):
    print(sum(nums) / len(nums))

avg = average([1, 2, 3])   # shows 2.0
print(avg)                 # None 😱
✅ Calculate and return, print outside
def average(nums):
    if not nums:           # GUARD CLAUSE
        return 0
    return sum(nums) / len(nums)

print(average([1, 2, 3]))  # 2.0
breakreturn
Exitsthe nearest loop (not the if)the whole function, loops included
Code after itthe rest of the function runsnothing runs (a break after return is dead code)

🔑 Rules

  • No return reached → the function gives None ("falls off the end")
  • Variables made inside stay inside → use return
  • return only works inside def
  • Early returns replace elif chains: each if can assume the earlier ones failed

⚠️ Side effects

scores.sort() inside a function also sorts the caller's list. Use scores = sorted(scores) unless changing it is the job.

def grade(score):           # early returns, no elif needed
    if score >= 90:
        return "A"
    if score >= 75:
        return "B"
    if score >= 50:
        return "C"
    return "F"

robot.get("height")          # None

for k, v in robot.items():   # both

🔑 Lists vs dictionaries

List = find by position (x[0]), for a sequence of similar things. Dict = find by key (d["name"]), for labelled data, lookups and counting. Phone numbers stay text ("9500262191"): they're labels, not quantities.
