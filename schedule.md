### 📱 How to commit from the phone (GitHub website)
1. Open **github.com/gowrifrank/learning-log** in Chrome (⋮ → **Desktop site** if the buttons are hidden)
2. Tap into the **`leetcode/`** folder (or `hackerrank/`) → **Add file** → **Create new file**
3. Name it like `2026-11-03_1470_shuffle_the_array.py`
4. Paste your accepted solution
5. Tap **Commit changes** → write the message → **Commit changes**
6. Done: today's square is green 🟩
